## Tooling notes for whoever comes next

- **Upstream renamed two of this ticket's test files.** `ClientTests/BrowserViewControllerStateTests.swift` and `ClientTests/BrowserViewControllerTests.swift` moved under `ClientTests/BrowserViewController/`. `git diff firefox-v147.2 c5afa25d3b -- <new path>` returns **nothing** for both, which reads exactly like "Ecosia never touched this file" — it is a lie. The conflict markers give it away (`<<<<<<< HEAD:<new path>` … `>>>>>>> …:<old path>`); diff against the old path.
- **zsh does not word-split unquoted variables.** A `for f in $FILES` loop over a newline-separated list silently becomes one iteration with a giant filename ("File name too long"). Use `while read` over a file.
- `swiftlint lint <explicit paths>` ignores `excluded:` *and* pulls in `included: [".", "/Users/vagrant/git"]`, so it lints `vendor/` and drowns the real output. Run bare `swiftlint lint --strict --quiet` from the repo root (the `swiftlint_baseline.json` applies) and grep the result for your paths.
